2 . 다음 C언어 프로그램의 실행 결과로 올바른 것은 무엇인가?

#include <stdio.h>

struct Person {
    char name[50];
    int age;
};

void updateAge(struct Person p) {
    p.age = 22;
}

int main() {
    struct Person p1 = {"Moon", 25};
    updateAge(p1);
    printf("Age: %d\n", p1.age);
    return 0;
}

1 . Age: 22
2 . Age: 25
3 . Age: 0
4 . 컴파일 오류가 발생한다.

4 . 다음과 같이 공용체 Data를 정의하고 사용했을 때, 메모리 구조와 동작에 대한 설명으로 가장 옳은 것은?

union Data {
    int i;
    float f;
    char str[20];
};

union Data data;
data.i = 10;
data.f = 220.5;

1 . 각 멤버가 독립적인 메모리 공간을 가지므로 data.i와 data.f의 값이 모두 온전히 유지된다.
2 . 공용체 data의 전체 크기는 모든 멤버의 크기를 합친 28바이트가 된다.
3 . 모든 멤버가 동일한 메모리 시작 주소를 공유하므로 data.f에 값을 대입하면 기존 data.i의 값이 덮어씌워진다.
4 . union 키워드 대신 struct 키워드를 사용해도 메모리 동작 방식은 완전히 동일하다.

5 . 다음 C언어 코드에서 열거형(enum)이 정의되어 있을 때, printf 함수로 출력되는 결과는 무엇인가?

#include <stdio.h>

enum TrafficLight {
    Red,
    Yellow,
    Green
};

int main() {
    enum TrafficLight signal = Green;
    printf("%d\n", signal);
    return 0;
}

1 . 0
2 . 1
3 . 2
4 . 3
